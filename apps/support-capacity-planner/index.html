Model notes

Staffing uses the Erlang C queueing model for a single pooled queue, stationary arrivals within the peak hour, identical agents, and exponential service times. It returns the smallest whole-agent count meeting both the service-level and 85% utilization cap. Real contact centers need interval-level arrival forecasts, shrinkage, skills, breaks, channel mix and empirical service distributions. This demo excludes those effects.

Planning aid only. Validate queue assumptions and local operating constraints with workforce-management data before making staffing decisions.

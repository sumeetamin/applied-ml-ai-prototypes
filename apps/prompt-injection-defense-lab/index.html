Defense-in-depth notes

Treat retrieved text as data, not authority. Separate system policy from untrusted context, constrain tools with server-side authorization, validate structured outputs, keep sensitive sources out of unnecessary prompts, and require human approval for consequential side effects. Logging and evaluation help surface failures; no single text classifier makes an agent secure.

This demo does not call an LLM, access files, send messages, or execute tools. Never use heuristic scores alone to allow a real agent action.
